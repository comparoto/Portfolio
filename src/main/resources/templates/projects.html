Conecta Arena

The Conecta Arena project was developed to create a web application for Arena Pernambuco, aiming to address the issues of low actual occupancy and underutilization of the space. The system enables a connection between the facility's management and the public, facilitating the promotion of cultural, sporting, and corporate events.

Key Features:

  • Scalable MVC architecture with Spring Boot
  • Relational database modeling (JPA/Hibernate)
  • Responsive and dynamic interface

Protege Agro

The Protege Agro project was developed to address the challenge of mapping climate vulnerability faced by many companies in the agricultural sector, helping to integrate data, monitor conditions, issue alerts, and adapt production chains. It is a platform for managing climate risks within agricultural supply chains; the expected outcomes include reduced losses from weather events, producers receiving advance alerts, increased adoption of resilient practices, and automated reporting on contributions to climate adaptation.

Key Features:

  • Connection to weather API
  • Contribution documentation
  • Easy-to-use interface
